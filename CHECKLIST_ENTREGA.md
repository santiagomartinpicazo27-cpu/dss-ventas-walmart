# Antes de entregar la actividad

- [ ] Descargar **Walmart Dataset** directamente desde Kaggle con la cuenta del integrante; confirmar que `Walmart.csv` coincide con el espejo y registrar fecha real.
- [ ] Ejecutar `python scripts/procesar_walmart.py Walmart.csv` y `python scripts/validar_dashboard.py`.
- [ ] Completar el grupo y reemplazar los enlaces de ejemplo por URLs reales y verificadas en portada/README. Materia, estudiante, carrera y fecha ya están integrados.
- [ ] Subir repositorio Git a la **cuenta propia** de GitHub y configurar Pages.
- [ ] Tomar capturas reales de **Settings → Pages**, de los **commits** remotos y del sitio publicado.
- [ ] Abrir URL pública en incógnito o en otro dispositivo y volver a probar tienda/año/festivos y exportación.
- [ ] Actualizar el PDF final con URLs y capturas que comprueben la publicación (el PDF incluido es una **versión previa**).
- [ ] Distribuir trabajo y commits propios entre los integrantes según lo pida el profesor; los commits locales de ejemplo se generaron en una sesión.
- [ ] Completar bitácora con los prompts realmente enviados por cada integrante y con su reflexión personal.

Nota: los sitios de GitHub Pages no deben almacenar contraseñas, claves de acceso ni datos privados.
